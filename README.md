# Excel Data Analytics Salary Dashboard
## Project Overview

My first data analytics project using Microsoft Excel.

The project analyzes data analyst and data-related job postings to explore salary information, job types, job titles, countries, and job counts.

I built this project while following a tutorial by Luke Barousse as part of my learning journey in data analytics.

## Project Objectives

The main objectives of this project were to:

- Practice cleaning and preparing data in Excel
- Remove duplicate records and make the data more suitable for analysis
- Use Excel functions to analyze salary data
- Use data validation to create interactive selections
- Calculate median salary for selected countries and job titles
- Analyze job counts by job type
- Build an interactive Excel dashboard

## Tools Used

- Microsoft Excel
- Excel formulas and functions
- Data Cleaning
- Data Validation
- Data Analysis
- Excel Charts

## Skills Demonstrated

### Data Cleaning

I worked with the dataset to:

I used Excel functions and calculations to analyze:
